# GoaDirectory coded website previews

Real, responsive HTML/CSS pages you can open and click in a browser (not images). Each direction has a homepage and a matching Counto Motors listing page, built from the actual site content.

**Gallery index:** [Open all previews](https://htmlpreview.github.io/?https://raw.githubusercontent.com/consecrating/GoaDirectory/a302e1f236bb61dc648c5d8289f571d08a9ff3fe/design-site/index.html)

> These render through the htmlpreview proxy because repository GitHub Pages could not be enabled with the available permissions. The pages are plain static HTML/CSS in `design-site/` and will also work on any static host or GitHub Pages once enabled.

## Recommended shortlist

1. **#1 Goa Atlas** — best overall identity + discovery + SEO structure.
2. **#4 Local First** — best accessibility and contact conversion.
3. **#9 Search Canvas** — fastest, cleanest, lowest build risk.

## What is in each page

**Homepage:** header + primary search (keyword / category / area), area quick-links, category browse, featured listings, latest listings, footer — using real GoaDirectory businesses and category counts.

**Listing page:** breadcrumb, single descriptive H1, expired-status notice, real Mercedes photo gallery (13 photos), sticky facts panel with Call / Directions / Contact / Save / Share, About section, static map with load-on-demand, and related Automobiles listings.

A thin dark bar at the bottom of each preview is a navigation aid between mockups and is not part of the design.
